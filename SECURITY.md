# Security Policy

## Supported versions

Movary is still under active development and has not reached version 1.0. Security
updates are provided for the latest published release. If you run an older version,
please update before reporting a vulnerability or requesting support.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue, discussion,
or chat channel.

Report vulnerabilities privately through
[GitHub's security advisory form](https://github.com/leepeuker/movary/security/advisories/new).
If that is not possible, email `lee.peuker@protonmail.com`.

Include enough information to reproduce and assess the issue, where possible:

- the affected Movary version or commit;
- a description of the vulnerability and its potential impact;
- steps to reproduce it or a minimal proof of concept; and
- any known mitigations or workarounds.

Do not include real user data, credentials, API tokens, or other secrets in the
report. Please allow the maintainers time to investigate and release a fix before
publicly disclosing the issue.

For non-security bugs and support requests, use the channels listed in the
[README](README.md#support).
