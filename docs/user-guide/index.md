# User guide

The User guide explains how to use and manage your own Movary account. Open **Settings** from the navigation menu to find account preferences, integrations, and application options.

## Account settings

The **Account** menu contains settings that apply only to your account:

- **General** controls your username, privacy, date format, movie-title display, and other preferences.
- **Security** controls your sign-in email, password, and two-factor authentication. See [Account and security](account-and-security.md).
- **API tokens** provides credentials for trusted API clients and automation. See [API authentication](api-authentication.md).
- **Locations** manages the places where you watch movies. See [Locations](../features/locations.md).
- **Dashboard** controls which statistics appear and how they are ordered.
- **Personal data** provides CSV import, export, and deletion actions. See [Personal data](personal-data.md).

Your privacy level determines who can see the movie data on your user pages. See [Privacy and sharing](privacy-and-sharing.md).

The **Integrations** menu connects Movary to services such as [Plex](../features/plex.md), [Jellyfin](../features/jellyfin.md), [Emby](../features/emby.md), [Kodi](../features/kodi.md), [Trakt](../features/trakt.md), and [Letterboxd](../features/letterboxd.md).

## Administrator settings

Users with the Admin role also see the **Server** menu. These settings affect the entire Movary installation and are documented under [Administration](../configuration.md). Regular users do not need access to server configuration to manage their own account.
