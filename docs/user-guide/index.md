# User guide

The User guide explains how to use and manage your own Movary account. Open **Settings** from the navigation menu to find account preferences, integrations, and application options.

## Using Movary

- [Movie tracking](tracking-movies.md) explains how to manage your history, ratings, and watchlist.
- [Browsing movies and people](browsing-movies-and-people.md) explains how to explore history, movie lists, actors, and directors.
- [Dashboard and statistics](dashboard-and-statistics.md) explains the activity overview and dashboard customization.

## Account settings

The **Account** menu contains settings that apply only to your account:

- **General** controls your username, privacy, date format, movie-title display, and other preferences. See [Preferences](preferences.md).
- **Security** controls your sign-in email, password, and two-factor authentication. See [Account and security](account-and-security.md).
- **API tokens** provides credentials for trusted API clients and automation. See [API authentication](api-authentication.md).
- **Locations** manages the places where you watch movies. See [Locations](locations.md).
- **Dashboard** controls which statistics appear and how they are ordered. See [Dashboard and statistics](dashboard-and-statistics.md).
- **Personal data** provides CSV import, export, and deletion actions. See [Personal data](personal-data.md).

Your privacy level determines who can see the movie data on your user pages. See [Privacy and sharing](privacy-and-sharing.md).

The **Integrations** menu connects Movary to media servers, players, movie services, and social platforms. See [Integrations](../features/integrations.md) to compare the available connections and open their setup guides.

## Administrator settings

Users with the Admin role also see the **Server** menu. These settings affect the entire Movary installation and are documented under [Administration](../administration.md). Regular users do not need access to server configuration to manage their own account.
