# Locations

Locations let you record where you watched each play, such as at home, at a friend's house, or at a cinema. Each account maintains its own list of locations.

## Manage locations

Open **Settings → Account → Locations**. If locations are disabled, select **Enable locations** before managing the list.

To add a location:

1. Select **Add location**.
2. Enter a name.
3. Select **Cinema** when the location is a movie theater.
4. Select **Create**.

The locations table shows whether each location is a cinema and how many plays are assigned to it. Select a row to rename the location, change its cinema status, or delete it.

Marking a location as a cinema makes its plays available to the **Last Plays Cinema** dashboard row. Deleting a location preserves the associated watch entries but removes their location assignment.

## Assign a location to a play

Choose a location from the location field when adding a play. To change the location later, open the movie page, select **View all** under the play count, and select the play you want to edit.

Locations belong to individual play entries. If you watch the same movie at different places or on different dates, each entry can use a different location.

The settings button beside the location field opens the location-management page when you need to add or edit an option.

## Location visibility

An individual play displayed on a movie page shows that a location is assigned, but does not show the location name to other viewers.

The **Top Locations** dashboard row does display location names and play totals. The **Last Plays Cinema** row displays movies watched at locations marked as cinemas. Anyone permitted to view your dashboard by your [privacy setting](privacy-and-sharing.md) can see enabled dashboard rows. You can hide either row under **Settings → Account → Dashboard**; see [Dashboard and statistics](dashboard-and-statistics.md#customize-the-dashboard).

## Disable locations

Select **Disable locations** under **Settings → Account → Locations** to hide the location field when adding or editing plays. Disabling the feature retains your locations and existing play assignments, so they return when you enable it again.

Dashboard rows are configured separately. Hide the location-related rows under **Settings → Account → Dashboard** if you do not want them displayed.
