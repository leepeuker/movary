# Browsing movies and people

Movary provides pages for exploring a user's viewing activity and the movies, actors, and directors represented in it. Open the navigation menu and select **History**, **Watchlist**, **All Movies**, **Top Actors**, or **Top Directors**.

These pages use the user selected at the top of the page. The available users depend on their [privacy settings](privacy-and-sharing.md). Changing the selected user keeps you on the equivalent page in that user's collection.

## Browse movie lists

**History** is the chronological record of viewing activity, including repeat watches. **Watchlist** contains movies saved for later, while **All Movies** shows each watched movie once. See [Movie tracking](tracking-movies.md) for managing these lists.

On **All Movies**, search by title or open **Advanced search** to:

- sort by title, release date, watch date, personal rating, IMDb rating, TMDB rating, or runtime;
- filter by genre, language, release year, production country, rating status or range, and watch location; and
- choose how many results appear on each page.

Select **Set defaults** to remember the selected sorting and filters for All Movies in the current browser. **Clear defaults** restores Movary's built-in sorting and unfiltered view on future visits, while **Reset** restores all current search controls to their built-in values. Use the view button to switch between poster and table layouts; the table shows additional details and supports sorting through its column headings. Movary remembers the selected layout in the current browser.

Select a movie to view its metadata and the selected user's rating, watch dates, and watchlist status. On your own pages, you can also add a play, change the rating, or update the watchlist.

## Browse actors and directors

**Top Actors** and **Top Directors** contain people credited in movies from the selected user's history. Both pages support name searches and poster or table layouts.

The advanced search options let you filter by gender, choose the page size, and sort by:

- **Unique appearances**, which counts distinct watched movies;
- **Total appearances**, which counts appearances across history records; or
- **Name**.

In the table layout, select a supported column heading to change the sorting directly.

Select **Set defaults** in advanced search to remember sorting and filters separately for Top Actors and Top Directors in the current browser. The Watchlist page provides the same option for its sorting and filters.

Select a person to open their detail page. It shows available biographical information and external TMDB or IMDb links. The **Acting** and **Director** tabs show watched movies associated with that person and, when available, matching movies from the watchlist.

## Privacy and shared pages

Movie and person lists are part of a user's shared pages. Whether another person can open them is controlled by the account's privacy level. Viewing another user's lists does not give you permission to change their history, ratings, or watchlist. See [Privacy and sharing](privacy-and-sharing.md) for the available visibility levels.
